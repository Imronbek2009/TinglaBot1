## 🆕 v7 versiyada YouTube Anti-Bot (`Sign in to confirm you’re not a bot`) xatoligi 4 bosqichli himoya bilan hal qilindi:
1. **⚡ 1-bosqich (Zero-Config `android_vr` + `tv_embedded` Bypass):** `yt-dlp` endi YouTube veb-sahifasini emas, balki captcha va bot-tekshiruv talab qilmaydigan ichki `android_vr` hamda `tv_embedded` API oqimlarini ishlatadi.
2. **🌐 2-bosqich (Avto Lokal Brauzer Cookie):** Agar kompyuterda `yt_cookies.txt` bo'lmasa va YouTube IP-manzilni tekshirsa, bot avtomatik tarzda kompyuterdagi brauzerlar (Edge, Firefox, Brave, Opera, Chrome) cookie'sidan foydalanib ko'radi.
3. **▶️ 3-bosqich (Admin Paneldan 1-tugmada `yt_cookies.txt` yuklash):** Serverda (Render/VPS) ishlatganda `👑 Admin Panel` -> `👁 Story va Cookie sozlamalari` -> `▶️ YouTube cookies.txt yuklash` orqali cookie fayl tashlab qo'yish imkoniyati qo'shildi.
4. **🔄 4-bosqich (Piped Public API Fallback):** Barcha urinishlar bloklansa ham, zaxira Piped serverlari orqali videoni tortib beradi.
